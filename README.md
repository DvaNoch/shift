# Дневник смен водителя

Учёт поездок за смену: список поездок за день, сводка по выручке, комиссии и оплате, простая страница для телефона.

Стек: Python 3.12, FastAPI, Pydantic 2, SQLite, pytest. Клиент — одна HTML-страница на чистом JS, её отдаёт сам FastAPI.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Страница: http://127.0.0.1:8000/ , документация API: http://127.0.0.1:8000/docs .
Данные из `trips.json` за 2026-10-01 … 2026-10-06; например, http://127.0.0.1:8000/?date=2026-10-01 .

При первом запуске создаётся `driver_shifts.db`, и в неё загружается `trips.json`. Повторные запуски файл не перечитывают. Чтобы загрузить его заново, удалите `driver_shifts.db`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DRIVER_SHIFTS_DB` | `driver_shifts.db` | путь к базе SQLite |
| `DRIVER_SHIFTS_SEED` | `trips.json` | файл с начальными поездками |

## API

### `GET /trips?date=YYYY-MM-DD`
Поездки за день в порядке начала.

### `GET /summary?date=YYYY-MM-DD`
```json
{
  "date": "2026-10-01", "trips": 2,
  "revenue": 3900.0, "commission": 585.0, "net": 3315.0,
  "cash": {"trips": 1, "revenue": 1500.0},
  "card": {"trips": 1, "revenue": 2400.0}
}
```
`net` — «на руки», выручка минус комиссия. За день без поездок возвращаются нули.

### `POST /trips`
```bash
curl -X POST http://127.0.0.1:8000/trips -H "Content-Type: application/json" -d '{"id": "t-100", "start": "2026-10-06T14:00:00+05:00", "end": "2026-10-06T14:30:00+05:00", "amount": 2000, "payment": "card", "commission": 300}'
```

| Ситуация | Ответ |
|---|---|
| новый `id` | `201` и созданная запись |
| тот же `id`, те же данные | `200` и существующая запись, дубль не создаётся |
| тот же `id`, другие данные | `409`, в `detail.fields` — список отличающихся полей |
| ошибка в данных | `422` |

Проверки: `amount > 0`; `0 <= commission <= amount`; не больше двух знаков после запятой; `end` позже `start`; `payment` — `cash` или `card`; время обязательно со смещением; лишние поля не принимаются.

## Что сделано и как

- **День поездки** определяется по дате начала в её собственном смещении. Поездка `2026-10-02T00:20:00+05:00` (в UTC это ещё 1 октября) попадает во 2 октября. Поездка, начатая в 23:40 и законченная после полуночи, относится к дню начала. Этот день вычисляется при записи и хранится в колонке `local_date` с индексом.
- **Деньги** хранятся целыми числами в тиынах (сотых долях тенге), а считаются в `Decimal`, поэтому сумма `0.1 + 0.2` даёт ровно `0.3`. В JSON суммы — обычные числа.
- **Комиссия** — сумма в тенге за поездку, а не процент.
- **Защита от дублей**: `id` — первичный ключ, вставка делается через `INSERT OR IGNORE`, затем данные сравниваются с сохранёнными в той же транзакции. Сравнение нормализованное: `1500`, `1500.0` и `"1500.00"` считаются одним значением. Время считается одинаковым, если совпадают и момент, и смещение: от смещения зависит день.
- **Загрузка `trips.json`** использует ту же функцию, что и `POST /trips`. Файл загружается целиком или не загружается вовсе. Если запись не проходит проверку, приложение не стартует и пишет её номер и `id`.
- **Клиент** (`static/index.html`): сводка (на руки, выручка, комиссия, число поездок), разбивка наличные/карта, список поездок. Переключение дня кнопками, выбором даты и стрелками клавиатуры; выбранный день хранится в адресе (`?date=`). Время поездок показывается в их собственном поясе. Суммы в формате `3 900 ₸`. На телефоне поездки идут карточками, начиная с 640px — таблицей. Учитывается тёмная тема системы.

## Структура

```
app/
  main.py      маршруты, загрузка trips.json при старте, отдача страницы
  models.py    Pydantic-модели и проверки
  db.py        схема SQLite и подключение
  service.py   день поездки, сводка, добавление без дублей, загрузка файла
static/index.html
tests/
  test_summary.py   сводка: обычный и пустой день, полночь, разные смещения
  test_trips.py     дубли, 409, проверки данных, повторная загрузка файла
  test_example.py   пример из задания за 2026-10-01
trips.json
```
